# M4ロッド → 1/4インチ スタジオアダプター

**Dr. SILICON / ZeroRoomLab**

中華製タブレット吸盤アーム（M4メスロッドタイプ）を、スタジオ照明・マジックアームで標準的な1/4-20オスダボに変換する3Dプリント製アダプターです。

![アダプタ写真](./images/adapter_photo.jpg)

---

## 概要

中華製タブレット吸盤アームのロッドソケットはM4メス規格です。スタジオ機材（リングライト・ボールヘッドブロック・アイスライトマウント等）は1/4-20オスダボを前提に設計されています。このアダプター1個でその差を埋めます。

CA複合化後処理により、実用スタジオ荷重に耐える剛性を実現しています。

- プリント時間：約15分
- モデリング時間：約5分
- フィラメントコスト：¥50以下

## プリント設定

| パラメータ | 値 |
|-----------|-----|
| 素材 | **ABS必須**（理由は後述） |
| ノズル温度 | 248 °C |
| シェル数 | 3層 |
| 底面層数 | 4層 |
| インフィル | 45 % |
| サポート | **不要** |
| プリント方向 | **逆Z**（M4ソケット面をベッドに置く） |

### ABSが必須な理由

PLAはシアノアクリレートの毛細管浸透を受け付けません。後述のCA複合化処理が剛性の主要な供給源であるため、PLAで出力した場合はせん断強度が大幅に低下します。PETGは不十分です。**ABS一択**です。

### 逆Z方向プリントの理由

- M4ボルト座面（ワッシャ当たり面）をベッドに置くことで、荷重集中点に最密・最平滑な層が来る
- 積層方向が主引っ張り軸と直交するため、引き抜き方向の層間剥離が発生しない
- オーバーハング側のテーパー・面取り形状がこの方向で自己支持角に収まるため、サポート材ゼロ・内径面も荒れない

---

## 後処理：ABS–CAコンポジット処理

この工程により、多孔質ABSプリントをハイブリッド複合材に変換します。単体ABSより大幅に高い剛性を得ながら、ABSの「折れる前にしなる」特性を残します。

1. **低粘度シアノアクリレート**（例：アロンアルファ プロ用 低粘度）を全露出面から多めに流し込む。毛細管現象でインフィル空隙に浸透させる。
2. **M4ボルトを挿入**し、CA未硬化のうちに着座させる。
3. **CAプライマー（硬化促進剤）**を部品の横からスプレーし、内部CAを同時硬化させる。過剰噴霧不要——横から短く吹くだけで十分。
4. 完全硬化後に組み付ける。

結果：ABSマトリクス＋CA充填＝XYせん断をコンポジット壁で受け、Z軸はM4ボルト＋ワッシャで機械的に拘束する構成（後述）。

## 組み付け

**別途用意するもの：**

- M4ボルト（相手アームのソケット深さに合わせた長さ）
- M4ワッシャ（素材選定は下記の電食注意事項を参照）

**荷重分担：**

- **Z軸（引き抜き方向）：** M4ボルト＋ワッシャによる機械拘束のみで担当。CAコンポジットはこの荷重を負わない。剥離モードを設計で排除している。
- **XY軸（傾き・せん断方向）：** アダプター本体のCAコンポジット壁と1/4-20ダボの嵌合長で担当。

---

## ⚠️ ボルト・ワッシャの素材選定——電食（ガルバニック腐食）について

異種金属接触部に水分が入ると電食が進行します。相手素材に合わせて選定してください。

| アーム素材 | ボルト・ワッシャ指定 |
|-----------|-------------------|
| **アルミ**（中華アームの大半はアルミダイキャスト） | **ステンレス**——電位差小さく問題なし |
| **鋳鉄・鉄系**アーム | **ユニクロ（亜鉛メッキ）**——ステンレス×鉄は電位差が大きく、湿潤環境で鉄側が腐食する |

判別方法：磁石で確認。アルミは非磁性→ステンレス。磁性あり→ユニクロ。

ワッシャもボルトと同素材で揃えること。

## 設計メモ

全径変化部にテーパーを設けることで、逆Z方向プリント時にすべてのオーバーハング面が自己支持角に収まります。水平オーバーハングは存在しません。これにより内径面が荒れず、CA浸透経路が均質になります。

インフィル45%は意図的な数値です。クランプ荷重に耐えるだけの密度を保ちながら、CAが断面全体に浸透できる空隙を確保するバランスです。高すぎるとCA複合効果が失われ、低すぎるとABSマトリクスの構造寄与が不足します。
